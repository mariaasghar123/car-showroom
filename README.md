# 🏎️ APEX MOTORS | Luxury & Exotic Car Showroom

A state-of-the-art frontend landing page UI for a luxury exotic car showroom, crafted with modern HTML5, CSS3, Tailwind CSS, and Vanilla JavaScript. Features ultra-HD studio photography, 3D card tilts, aerodynamic particle canvas animations, and interactive client services.

---

## ✨ Features

- **Cinematic Hero Experience**: Fullscreen hypercar hero with real-time 60 FPS HTML5 `<canvas>` aerodynamic particle streamlines and amber glowing embers.
- **Live Performance Counters**: Animated count-up ticker displaying 0-60 MPH acceleration, peak horsepower, top velocity, and worldwide showroom presence.
- **Interactive 3D Card Tilt**: Mouse-following 3D perspective tilt effect on vehicle cards with dynamic specular glare overlays.
- **Showroom Fleet Filtering & Search**: Instant filtering by category (*All Vehicles, Hypercars, Track Specials, Grand Tourers*), keyword search, and multi-criteria sorting.
- **Exterior Paint Finish Switcher**: Interactive paint color swatches updating vehicle thumbnails in real time.
- **Cockpit & Chassis Telemetry Hotspots**: Interactive markers over the driver cockpit highlighting F1 steering telemetry, quad-motor powertrains, active aerodynamics, and carbon-ceramic brakes.
- **Synthesized Supercar Sound & Equalizer**: Web Audio API engine sound simulation with responsive neon sound wave visualizer bars.
- **Bespoke Lease & Financing Calculator**: Real-time lease estimation sliders with customizable acquisition price, down payment, and loan duration.
- **VIP Private Viewing & Test Drive Booking**: Multi-salon reservation modal with date picker and VIP concierge options.
- **Private Portfolio**: Save favorite vehicles to a personal collection stored in `localStorage`.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure and accessible dialogs.
- **CSS3 / Tailwind CSS**: Glassmorphism, custom responsive layouts, keyframe animations, and glowing neon accents.
- **Vanilla JavaScript**: Zero external runtime dependencies, 3D perspective calculations, canvas animation loop, and Web Audio API synthesizer.
- **Assets**: Ultra-high definition 1080p curated studio automotive photography.

## 🚀 Getting Started

### Clone the Repository
```bash
git clone https://github.com/mariaasghar123/apex-motors.git
cd apex-motors
```

### Run Locally
Open `index.html` directly in any browser or launch a local static server:
```bash
# Using Python
python3 -m http.server 8080

# Using Node.js npx
npx serve
```
Visit `http://localhost:8080` in your web browser.

---

## 🌐 Deployment to Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Root directory: `./`).
3. Click **Deploy** — your showroom goes live in seconds!
